# Hello People Social

Templates live in `web/social.html`; ready to post PNG exports in `assets/social/`.

## The formats

| Template | Size | Use |
|---|---|---|
| Tip / educational | 1080 x 1080 | Teach one small thing. Build authority. |
| Before / after | 1080 x 1080 | Show time saved. Our signature proof. |
| Offer / CTA | 1080 x 1350 | Book the audit. Solid blue, brand forward. |
| Story / Reel cover | 1080 x 1920 | Hook for a carousel or reel. |
| LinkedIn | 1200 x 627 | Thought leadership, landscape. |

## Rules (so every post looks like us)

1. **One idea per post.** If it needs two headlines, it is two posts.
2. **95 / 5 gradient.** Solid blue or clean neutrals carry the post. The gradient
   shows up once (the "after" panel, one highlighted word, a thin accent bar).
   Never a full gradient background. Solid brand blue as a full background is fine.
3. **Poppins for the statement, Inter for the rest.** Big, confident headline.
4. **Voice.** Plain and human, sell the outcome, no buzzwords, no dashes.
   See `voice-and-tone.md`.
5. **Always sign off** with the logo and `@hellopeople_agency` (or `hellopeople.ca`).
6. **Keep the safe zone.** On Stories/Reels, keep text clear of the top and
   bottom ~250px so UI and captions do not cover it.
7. **Contrast holds.** White or ink text only on solid color or the gradient,
   never small text on top of a busy image.

## Caption starters (brand voice)

- "If a task feels like copy and paste, it can probably be automated. Here is where to start."
- "We turned a two day job into a two hour one. Here is how."
- "Your team should be doing the work only people can do. We will handle the rest."
